# Красен Камбуров — авторски сайт

Публичен сайт: https://asparuhkamburov.github.io/patyat-na-oslepenite/

Статичен сайт за GitHub Pages. Начална страница, каталог с филтри и търсене, биография и отделни страници за 15 заглавия от подбраната библиография.

## Обновяване

Съдържанието и шаблоните са в `scripts/build.py`. След редакция:

```sh
python3 scripts/build.py
```

Стилове: `assets/site.css`. Навигация и филтри: `assets/site.js`. Генерираните HTML страници се включват в commit, защото Pages публикува корена на `main` без стъпка за компилация.

Съществуващите файлове `patyat-na-oslepenite.pdf` и `patyat-na-oslepenite.epub` запазват адресите и съдържанието си. Старите връзки към `#book`, `#award` и `#context` се пренасочват към страницата на романа. Началната страница запазва `#author`, `#works` и `#edition`.

„Осияние днес“ използва избраната корица (вариант 5, без издателското лого). Страницата обозначава електронното издание като предстоящо; файлове за изтегляне не са публикувани. Добавят се след финализиране на изданието и ISBN.

Биографията и библиографията са пренесени от предишния сайт. Непосочени години и непредоставени корици не се допълват по предположение. Изходните литературни текстове запазват авторските си права.
