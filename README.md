# Сайтът на Красен Камбуров е преместен

Нов сайт: https://krasenkamburov.github.io/

Основно хранилище: https://github.com/krasenkamburov/krasenkamburov.github.io

Това хранилище поддържа старите връзки: HTML страниците пренасочват към новия сайт, а публикуваните PDF и EPUB остават достъпни на досегашните адреси. Историята и всички файлове са копирани в новото хранилище.

Промени по авторския сайт се правят в новото хранилище. `scripts/build.py` тук генерира само страниците за пренасочване.
